Project Summary: Network Speed Monitor
Project Overview
Network Speed Monitor is a lightweight, Windows-only utility that measures real internet speed while bypassing VPN tunnels. It helps users identify the worst time periods (daily/weekly) for network performance by collecting continuous speed samples and visualizing trends through an intuitive dashboard.
Problem Statement
VPNs mask true physical network performance by routing traffic through encrypted tunnels. Users cannot identify if slowdowns come from their ISP, Wi-Fi interference, or the VPN itself. This tool solves that by monitoring physical adapters directly.
Main Features
Feature
	Description
	VPN-aware polling
	Automatically detects and filters out virtual/VPN adapters using WMI + route analysis
	Randomized intervals
	Polls every 3-5 minutes (prevents alignment with periodic network events)
	Daily summaries
	24-hour speed graph with minute-resolution data
	Weekly trend view
	7 stacked daily graphs for pattern recognition
	Worst-time analysis
	Identifies slowest 15-minute windows per day/week
	Portable deployment
	Single EXE + embedded React, runs from USB drive
	Low resource usage
	< 30 MB RAM, < 0.5% CPU idle
